# PalaeoKids store and permission checklist

## Identity
- App name: PalaeoKids
- Website: https://www.indianpalaeodb.in/
- Education category.

## Child-directed compliance
- Declare the actual intended age groups in Play Console / App Store Connect.
- Content must be age-appropriate.
- Avoid behavioral advertising and unnecessary identifiers.
- Maintain a clear privacy policy covering children, data collection, third-party services, retention, parental contact, and deletion/contact methods where applicable.
- Review every embedded third-party widget/video/analytics service.

## Recommended v1 permissions
Android:
- INTERNET
- ACCESS_NETWORK_STATE

Only add later when a feature truly needs it:
- Camera: fossil/sample photography.
- Photo library/media picker: attach an existing image.
- Approximate location: only for a genuinely useful nearby-site feature.
- Notifications: only for explicit opt-in learning reminders.

Avoid unless essential:
- Contacts
- SMS/call log/phone
- Precise/background location
- Microphone
- Broad all-files storage

## Store assets
- 1024×1024 master app icon
- Phone/tablet screenshots
- Feature graphic
- Short and full descriptions
- Support URL
- Privacy-policy URL
- Age/content-rating answers
- Data-safety/privacy answers
- Reviewer notes explaining native and live-web components
